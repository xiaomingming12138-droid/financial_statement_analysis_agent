01 / AGENT ENGINEERING

不是单次问答封装

工具参数由 Pydantic 验证；调用轨迹包含参数、结果摘要、耗时与错误。服务对重试、调用数和总时长设置边界。

02 / FINANCIAL TOOLS

让数字可复核

计算输入必须出现在已检索的原文引文中。使用十进制运算，检查单位一致性、零分母与负数基期；公式与输入可展开查看。

03 / EVALUATION

验证能力与边界

仓库提供离线评测与自动化测试，覆盖引用、计算、证据不足、文件上传和模拟模型的工具循环。实际模型质量需接入后单独评测。
